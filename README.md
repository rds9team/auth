# Discord 認証 Bot (auth)

discord.py 製の Discord 認証 Bot。

## 導入

https://discord.com/oauth2/authorize?client_id=1516079643709411378

## 主な機能

- **認証パネル設置 (`/set-panel`)**: エフェメラル設定画面から付与ロール・ログ先・方式・タイトル等を設定してパネルを設置
- **ログチャンネル設定 (`/set-log-channel`)**: サーバーごとの認証ログ通知チャンネルの設定・解除
- **認証方式**:
  - ワンクリック認証: ボタン押下でロール付与
  - 計算問題認証: ランダムな足し算の回答を入力
  - CAPTCHA認証: 4桁の確認コードを入力
  - 合言葉認証: 指定されたキーワードを入力
  - 利用規約同意: パネルの規約を確認し同意文言を入力
- **未認証ロール剥奪**: 認証完了時に未認証ロールを削除
- **制限ロール機能**: 特定ロール所持者の認証ブロックおよびログ通知
- **レートリミット**: 連打防止（3秒クールダウン）
- **統計・情報コマンド**: `/stats`, `/ping`, `/help`
- **ウェルカムDM**: 認証完了時の案内DM送信

## セットアップ手順

### 1. 依存関係のインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定

`.env.example` をコピーして `.env` を作成し、必要な値を設定します。

```env
DISCORD_TOKEN=your_bot_token_here
CLIENT_ID=your_client_id_here
```

### 3. Botの起動

```bash
python main.py
```

## コマンド一覧

| コマンド | 権限 | 説明 |
|---|---|---|
| `/set-panel` | 管理者限定 | 設定画面を開き、付与ロール・ログ先・方式などを設定してパネルを設置 |
| `/set-log-channel` | 管理者限定 | サーバー個別の認証ログ通知チャンネルを設定・解除 |
| `/stats` | 全員 | サーバーのメンバー数やBot稼働状況を表示 |
| `/ping` | 全員 | Botの応答速度（Ping）を測定 |
| `/help` | 全員 | コマンドと使い方のヘルプを表示 |
