# Discord 認証 Bot (auth)

Python (`discord.py`) で動作する、高機能で安全な Discord サーバー向け認証 Bot です。

## 導入

https://discord.com/oauth2/authorize?client_id=1516079643709411378
こちらのリンクから導入もできます

## 主な機能

1. **簡単セットアップパネル (`/setup`)**
   - ロール選択・ログチャンネル選択・認証方式選択をEmbedのセレクトメニューから直感的に設定
   - タイトル・説明文・合言葉などをモーダルで簡単編集し、ワンボタンでパネル設置
2. **認証パネル設置 (`/set-panel`)**
   - コマンド引数から直接認証パネルを設置（従来通りの方法もサポート）
3. **サーバー別ログチャンネル管理 (`/set-log-channel`)**
   - `.env` 固定だけでなく、サーバーごとにログ送信先をコマンドやセットアップ画面から自由に設定可能（未設定時は `.env` にフォールバック）
4. **多彩な認証方式**
   - **ワンクリック認証**: ボタンを押すだけで即座にロールを付与
   - **計算問題認証**: スパムBot対策としてランダムな足し算の答えを入力
   - **CAPTCHA認証**: ランダムな4桁の確認コード入力
   - **合言葉認証**: ルール等に記載されたキーワードを入力
   - **規約同意認証**: パネルに表示された利用規約を確認し「同意する」と入力
5. **未認証ロールの自動剥奪**
   - 認証完了時に、指定した未認証ロールを自動で削除
6. **ブラックリストロール制限 (要注意ロール対策)**
   - 特定のロール（要注意・制限ロール等）が付与されているユーザーの認証を自動ブロック
   - ブロック発生時や入力ミス発生時はログチャンネルへ警告・失敗通知
7. **クールダウン・連打防止 (Rate Limit)**
   - 連続でのボタン連打やDoS行為を自動で抑制（3秒の待機時間）
8. **認証統計・情報コマンド**
   - `/stats`: サーバー内の認証人数・未認証人数・認証率やBotの稼働時間・Pingを表示
   - `/ping`: WebSocket Ping を測定
   - `/help`: コマンドと機能の詳しいヘルプを表示
9. **ウェルカムDM案内**
   - 認証完了時にユーザーへ自動で案内DMを送信
10. **ステータス自動ローテーション**
    - 10秒ごとに「〇〇人 \| 〇〇鯖」「ping 〇〇ms」「Powered by rds9」を切り替え表示

## セットアップ手順

### 1. 依存関係のインストール

```bash
pip install -r requirements.txt
```

### 2. 環境変数の設定

`.env.example` をコピーして `.env` を作成し、必要な値を設定します。

```env
DISCORD_TOKEN=your_bot_token_here
CLIENT_ID=your_client_id_here
ROLE_ID=your_default_role_id_here
UNVERIFIED_ROLE_ID=your_unverified_role_id_here # 任意（認証時に剥奪するロール）
BLACKLIST_ROLE_ID=your_blacklist_role_id_here   # 任意（認証を禁止するブラックリストロール）
LOG_CHANNEL_ID=your_log_channel_id_here         # 任意（認証ログ通知チャンネル）
```

### 3. Botの起動

```bash
python main.py
```

## コマンド一覧

| コマンド | 権限 | 説明 |
|---|---|---|
| `/set-panel` | 管理者限定 | 認証パネルを設置（付与・剥奪・ブラックリストロール、認証方式、規約などを指定可能） |
| `/stats` | 全員 | サーバーの認証統計やBot稼働状況を表示 |
| `/ping` | 全員 | Botの応答速度（Ping）を測定 |
| `/help` | 全員 | コマンドと使い方のヘルプを表示 |
